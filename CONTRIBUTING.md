# Contributing

Thanks for looking. Issues are welcome: bugs, ideas, questions, and
anything that got in the way of capturing a note.

**Pull requests with code are not accepted yet.** qot is a one-person
project that will become a paid service, and keeping the copyright in one
place keeps two options open: shipping the GPL-family code on Apple's App
Store, and changing the license of future versions if that is ever needed.
Accepting outside code would first need a contributor license agreement,
which doesn't exist yet. If you've found a fix, describe it in an issue and
it will be credited when it lands.

The reasoning: [docs/records/2026-11-04-open-source-or-closed.md](docs/records/2026-11-04-open-source-or-closed.md).
